# EX1 LEGEND

صفحه معرفی و نسخه وب اپلیکیشن EX1 LEGEND به‌همراه پروژه مستقل اندروید.

- صفحه اصلی: معرفی EX1 و وضعیت انتشار APK
- نسخه وب اپلیکیشن: `/app.html`
- پروژه اندروید: `android/`
- Backend: همان پروژه Supabase فعلی؛ این تغییرات هیچ migration یا تغییر دیتابیسی اجرا نمی‌کنند.

## ساخت APK
Workflow با نام **Build Android APK** در GitHub Actions با هر push به شاخه طراحی یا به‌صورت دستی اجرا می‌شود. خروجی APK به‌صورت artifact ذخیره می‌شود. قبل از انتشار عمومی باید نصب، ورود، لینک‌های عمیق و عملکرد روی دستگاه واقعی بررسی شوند.

مسابقات رایگان‌اند و امتیازها ارزش نقدی، قابلیت خرید، انتقال یا برداشت ندارند.
